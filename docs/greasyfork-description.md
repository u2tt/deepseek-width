调整 chat.deepseek.com 对话内容区的宽度，宽度按窗口的比例计算，改变窗口大小时内容区跟着变。附带把思考过程收起到一行标题的功能。设置面板不常驻，从 Tampermonkey 菜单打开。

## 功能

- **宽度无级调节**：30% 到 100% 连续可调，步长 1%。100% 是当前窗口可用的内容宽度，30% 是可识别内容列的下限。
- **按比例生效**：宽度写成百分比，不写像素值。拖动或缩放浏览器窗口后内容列按新窗口宽度重新计算，不需要重新拖动滑块。
- **快捷档位**：面板内提供 满宽 / 90% / 80% / 70% / 原生 五个按钮。「原生」用于临时回到站点原始布局，比较改动前后的差异。
- **设置面板按需弹出**：页面上没有常驻控件，安装后界面与原来一致。需要调节时从油猴菜单打开面板，关闭后不留痕迹。
- **自动收起思考过程**：思考块保留「已思考（用时 N 秒）」这一行标题，正文收起。点击这一行仍然可以展开查看全文，展开与收起用的是站点自带的按钮，行为与手动点击一致。手动展开过的块不会被再次收起，正在输出的「思考中」块不做处理。
- **设置持久化**：宽度百分比和两个开关的状态保存在浏览器本地，刷新页面、重开标签页后保持上次的数值。
- **重新识别**：站点结构变化导致内容列没有被识别到时，点面板里的「重新识别」重新扫描；「复制诊断」输出当前识别结果，反馈问题时可以附上。

## 使用

1. 从本页安装脚本，确认 Tampermonkey（或 Violentmonkey）已启用。
2. 打开 https://chat.deepseek.com/ 。
3. 点浏览器工具栏的 Tampermonkey 图标，选「⚙ 打开设置面板」。也可以按 Alt+Shift+W。
4. 拖动滑块调节宽度，或点快捷档位。滑块上可以用滚轮微调，面板可以拖动标题栏移动位置。
5. 按 Esc 或点面板右上角的 × 关闭。

关闭面板后设置立即生效，不需要刷新页面。

## 权限说明

- `GM_getValue` / `GM_setValue`：保存宽度百分比、总开关、思考过程开关。
- `GM_registerMenuCommand`：提供面板入口。

脚本不加载远程代码，不发起网络请求，不读取页面内的对话内容，不上传任何数据。宽度修改由注入的一段 CSS 完成。

## 兼容性

- 站点：chat.deepseek.com，包含 /share/ 分享页。
- 浏览器：Chrome、Edge、Firefox、Safari，配合 Tampermonkey 或 Violentmonkey 使用。
- 窗口很窄时不强行压缩：内容列的识别有最小宽度阈值，找不到合适的目标时保持站点原生布局。

## 已知限制

- 只修改浏览器端样式，不影响服务端返回的内容和排版数据。
- 思考块的识别依据标题文本（已思考 / 思考中 / 正在思考 / 思考完成 / Thought for / Thinking），站点更换文案后需要等脚本更新。
- 移动端与触屏手势未做验证，桌面浏览器为验证环境。
- 「原生」档位只是临时对照，刷新页面后恢复上次保存的百分比。
